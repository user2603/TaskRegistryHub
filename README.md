# TaskRegistryHub

A small collection of automation tasks maintained by the platform tooling
team. Each developer works on a `dev/*` branch and lands new task folders
under `tasks/pool/`.

- The readiness policy currently in force: `docs/policies/task_readiness_policy.md`
- The task folder convention: `tasks/examples/`
- Superseded policy versions and old tracker exports live under
  `docs/policies/archive/` and `docs/archive/` (history only).

This repository is public. If you keep running into GitHub API rate limits
while reading it, fetch a full snapshot of a branch instead, e.g.
`https://codeload.github.com/<owner>/TaskRegistryHub/tar.gz/refs/heads/<branch>`.
