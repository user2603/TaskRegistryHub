# Task folder convention

Every task is one folder under `tasks/pool/` (maintenance tasks live under
`tasks/pool/maintenance/`) and follows the layout shown in
`task_template.json`. The authoritative list of required files, the status
bands and the tracker columns are defined by the readiness policy version
currently in force (`docs/policies/task_readiness_policy.md`). Do not rely on
older policy versions under `docs/policies/archive/` for the current rules.
